# Instalación por el arquitecto

Con el permiso del usuario, copiar únicamente `docs/codex-skill/jarwis-hoy/SKILL.md` a `%CODEX_HOME%\skills\jarwis-hoy\SKILL.md`; si `CODEX_HOME` no está definido, usar `%USERPROFILE%\.codex\skills\jarwis-hoy\SKILL.md`. Crear la carpeta si hace falta y comprobar que ambas copias coinciden. Esta nota no forma parte de las instrucciones del skill y no es necesario instalarla.

La orden JW-34-6D solo modifica la copia del repositorio: el ejecutor no debe instalarla ni tocar el skill del perfil. La instalación no habilita escrituras o borrados por el skill ni acceso a fuentes adicionales. No copiar archivos de evidencia ni un `hoy.json` ficticio al perfil. JarWis genera el archivo real al consultar con `shareToday` encendido.
